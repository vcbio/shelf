⛔ 최상위 색 금지선 — 형광색 금지 (대표 강한 지시 2026-07-27, 2회 강조)

형광·네온 계열은 대표의 특별 요청이 없으면 일절 쓰지 않는다. 무채색 계열이 기본값이다.
대표 원문: "어지간하면 형광색은 쓰지마라 한국사람들 형광색 안좋아해 무채색 계열만 쓰자" / "나도 형광색 굉장히 싫어하니깐 우리 작업할때 내 특별한 요청 없으면 디자인 작업할때 형광색 계열은 사용하지마"
  • 적용 범위: 제안덱·홈페이지·랜딩·대시보드·로고·차트·SNS·시안·내부물 전부. 내부물 예외 없음.

    • 검산: 금지 대상 7색(#D7F06A 90.7/66.5 · #C6FF2E 93.3/94.4 · #37FFA9 89.5/72.0 · #e2ff54 95.3/81.0 · #d4ff00 94.1/98.8 · #00ff19 87.8/117.8 · #00FF44 87.9/109.4) 전부 검출, 오탐 0(고채도 원색 #fe7902·#f6042e·#294aff와 활성 토큰 {colors.orange-key} 63.1/80.7 · {colors.orange-gold} 78.0/63.7 · {colors.gold} · #C0CEA6는 통과).

  • 대체 기본: 무채색(흰·크림·회색·차콜). 다크 그린 배경 위 주버튼 = 크림 화이트 #FBFBF8 + 딥그린 #0B3A2A 글자(대비 12.26:1 실측 검증 2026-07-27).
  • 브랜드 그린(#1F7A4D·#114A35·#0B3A2A)·차콜·베이지는 형광이 아니므로 계속 사용한다.
  • 강조는 채도를 올리지 말고 명도 대비·굵기·여백으로 만든다.
  • 이 금지선은 아래 프리셋 정의·토큰표보다 상위다 — 토큰에 정의돼 있다는 이유로 형광색을 쓰지 말 것. hot-orange·electric-blue를 쓸 때도 형광 채도는 금지이며, 대담함은 면적·대비·타이포로 낸다.
  • 조치 이력: hot-lime 프리셋(딥블랙+네온 라임)은 사용중지로 이 파일에서 토큰째 제거됐다. 구 규칙 "공식 제출 전 내부물은 hot-* 기본"도 폐기.

Overview (Brand & Style)

VCBio 규격은 1970년대 대학 세미나 핸드아웃의 차분함에 현대 바이오테크의 정밀함을 얹은 톤이다. 대형 식품·제약 브랜드사에 원료를 제안하는 B2B 문서가 주 무대이므로, 기본 인격은 차분·신뢰·보수다 — 과장된 색면보다 절제, 장식보다 위계, 근거 중심.

calm-charcoal의 축은 딥그린 키컬러 {colors.deep-green} + 곡물톤(크림 {colors.cream}·베이지 {colors.beige})이다. 딥그린은 검증된 선택지 중 하나이며 브랜드 고정색이 아니다 — 색은 건별로 고른다(위 🚫 절). 이 프리셋을 골랐을 때 딥그린이 주역을 맡고 곡물톤이 바탕을 데우는 구조이며, 화이트가 아닌 크림을 바탕으로 쓰는 이유는 유기적·따뜻한 인상 때문이다.

한 산출물은 프리셋 하나를 키로 잡는다. 공식 제출·IR·식약처 톤이면 calm-charcoal(검증됨), 캠페인·표지 임팩트면 hot-orange(형광 채도 금지), 웹 대시보드·테크 제안이면 electric-blue(형광 시안 금지)로 통째 교체한다. 프리셋을 섞지 않는다. 어느 것도 자동 기본값이 아니므로 착수 시 색 방향을 대표에게 올려 낙점받는다.

이 문서는 웹앱 UI 규격이 아니다. 소비 주체는 사람이 아니라 덱을 빌드하는 에이전트이고, 산출물은 제안덱·브로셔·대시보드·모션클립이다(→ Output Formats).

Colors

아래 팔레트는 calm-charcoal 프리셋의 것이다 — 딥그린 키컬러 + 고대비 곡물톤 중립. 브랜드 고정색이 아니라 선택지 하나이며(위 🚫 절), 다른 색 방향이 그 건에 맞으면 대체 프리셋이나 별도 후보로 간다. 역할 분류:

  • Brand(해당 프리셋 한정) — 딥그린 {colors.deep-green}(키컬러), 강조 그린 {colors.accent-green}(다크 위 룰선·배지), 골드 {colors.gold}(제한 강조).
  • Surface — 크림 {colors.cream}(기본 배경), 잉크 {colors.ink}(다크 배경), 다크 카드 {colors.panel-dark}·들린 카드 {colors.panel-raise}, 크림 위 흰 카드 {colors.white-card}·연초록 카드 {colors.tint-green}.
  • Text — 크림 위 본문 {colors.ink-text}, 다크 위 보조 텍스트 {colors.beige}.
  • Semantic(증감) — 상승 {colors.green-up}, 하락 {colors.red-down}. 나쁜 수치도 빨강으로 정직하게 노출한다(숨기면 더 의심받음). 데이터 의미 전달용이라 면적 제한 밖(단 칩 크기는 작게).

의미 역할 별칭(구글 규격 호환 슬롯 — 브랜드 고정색 선언이 아니다): {colors.primary} = 딥그린, {colors.neutral} = 크림. 다른 색을 고른 건에서는 이 슬롯의 값이 바뀐다. 모든 토큰은 {colors.<이름>}로 참조한다 — HEX는 프론트매터가 유일한 기재처다.

대체 프리셋(기본 calm-charcoal을 통째 교체):

  • hot-orange — 차콜 {colors.orange-bg} + 핫 오렌지 키 {colors.orange-key} + 보조 골드 {colors.orange-gold}. 형광(네온) 오렌지 금지. 단 {colors.orange-key}(63.1/80.7)·{colors.orange-gold}(78.0/63.7)는 기계 판정식(L* ≥ 85 AND C* ≥ 66)에 걸리지 않아 존치 확정(2026-07-27).
  • electric-blue — 푸른 다크 {colors.eblue-bg} + 테크 키 {colors.eblue-key}, 신뢰 강조 {colors.eblue-accent}, 네이비 표지면 {colors.eblue-navy}. 형광 시안 금지 — 차분한 블루만.
차트 시리즈 색은 즉흥이 아니라 ColorBrewer 학술 스킴(seq-green/blue·div-BrBG/RdYlGn·cat-Set2)에서 고른다 — 색맹·흑백인쇄 안전. 본문 대비·보더는 Radix sand 12스텝(본문 11~12·보더 6~7·카드면 3~4)을 역할 고정으로 쓴다. 값 정본은 통합규격 §1-K·§1-L.
편입 범위(의식적 제외): 이 파일은 프리셋 3종(calm-charcoal·hot-orange·electric-blue) + 증감 델타 + 의미 별칭, 합계 토큰 27개(고유 HEX 25종)만 담는다. 정본의 나머지 색(다크 베이스 톤 라이브러리 §1-J, 차트 스킴 HEX §1-K, 회색조 12스텝 §1-L, 내부도구 UI 분기색 등)은 파생본을 무한정 키우지 않기 위해 의도적으로 제외 — 필요 시 정본 해당 절을 직접 참조한다.

Typography

폰트는 Pretendard 단독(정본)이다 — 제목·본문·데이터·표지 전부 Pretendard, 위계는 크기·웨이트 차이로만 만든다. 다른 폰트는 대표 명시 요청 시에만 옵션 풀에서 꺼낸다. 모션클립 트랙만 예외로 GMarket Sans(→ Output Formats).

Pretendard는 Thin(100)~Black(900) 9웨이트가 있고, 극단 대비(Thin 거대 + Black 키워드)가 표지 임팩트를 만든다. 정본 웨이트 역할: w-thin(100)=표지 mega 얇은 거대 타이포, w-regular(400)=본문, w-bold(700)=제목·강조, w-black(900)=표지·디바이더 핵심어.

Layout & Spacing

8px 기본 리듬으로 수직 간격을 통일한다: {spacing.space-1}(8) → {spacing.space-2}(16) → {spacing.space-3}(24) → {spacing.space-4}(40). 카드 사이는 {spacing.gutter}(24px), 슬라이드·섹션 안전여백은 {spacing.margin}(64px), 정렬 격자는 {spacing.grid}(12col).

웹의 "1200px max-width" 전제는 쓰지 않는다. 대신 덱 세이프에어리어로 번역한다 — 제안덱 슬라이드는 1280×720px(13.333"×7.5", 96dpi) 캔버스에 margin 64px 안전여백을 지킨다. 레이아웃 리듬은 표지 → 디바이더 → 본문 → 마무리 4부. 다크/크림 교차는 최대 2연속(calm-charcoal), hot-*는 다크 단색을 유지한다.

Shapes & Imagery

모서리 반경: 카드 {rounded.card}(10px 기본)·{rounded.card-lg}(14px 대형), 배지/알약 {rounded.pill}(999px). 세분 sm/md/lg/xl 스케일은 TODO(정본 미확정) — 정본은 카드·필만 규정한다.

위 알파는 근흑색 다크(#1C1C1A)·흰 라이트 기준 예시값이다. 배경이 바뀌면 그 배경에서 3:1을 만족하는 최솟값을 다시 계산한다 — 배경 명시 없는 대비값은 쓰지 않는다.

접근성 실측: 글자 대비는 전 항목 4.5:1 통과(최저 12.26:1). 보조버튼 테두리 알파는 한국 실측 원값(.25~.28·#DDDDDD)이 경계 대 배경 대비 1.12~2.53:1로 3:1에 미달이라 다크 .36(근흑색 배경 3.33:1)·라이트 .44(#FFFFFF 3.24:1 / #FBFBF8 3.22:1)로 올려서 통과시켰다 — 형태·굵기·라운드는 실측 그대로이고 올린 것은 테두리 알파뿐이다(기준 WCAG 1.4.11 비텍스트 대비 3:1, 테두리는 바깥 배경과 버튼 면 양쪽에 대해 본다).

배경별 재계산 필수 구간: 딥그린 배경에서는 .36이 미달이다(#0B3A2A 2.98 / #114A35 2.71 — 배경 기준). 또한 C형 보조버튼은 면에 rgba(255,255,255,.10) 틴트가 깔려 테두리 대 면 기준을 함께 봐야 하며, #114A35에서는 .36=2.40 / .45=2.92(미달) / .55=3.57 ✅ 이므로 .55 이상을 쓴다.

폐기 — 유리(글래스) 버튼: 배경 11색 전부 경계 대비가 3:1에 미달했다 — 경계 대 버튼면 실측 1.37~1.91:1(최고 1.91 = 무채색 단색 #1C1C1A류, 딥그린 #114A35는 1.69, 라이트 배경은 1.37대), 버튼면 대 배경은 1.12~1.24:1 — "버튼으로 안 보인다". 유리는 표면(네비바·카드)에만 쓰고 누르는 컨트롤에는 쓰지 않는다. 실측 근거 = work-staging 2026-07-27_glass-button-test.

위 HEX·CSS 값은 버튼 정본 노트의 인용값이라 예외적으로 본문에 적는다(색 토큰의 HEX 기재처는 여전히 프론트매터 하나뿐이며, 버튼 값은 colors 토큰이 아니라 컴포넌트 실측 스펙이다).

Motion

모션클립은 대본 문장마다 {motion.clipDuration} 길이의 무음 클립이 기본 단위다. 화면에는 자막 문장을 그대로 쓰지 않고, 판정 단어·숫자·브랜드명 1~3개만 새로 띄운다.

모든 디자인 산출물에 apple-design 스킬을 기본 발동한다(대표 지시 2026-07-16 — 따로 선택 안 해도 적용). 정적물(인쇄 덱·A4)엔 타이포(옵티컬 사이징·자간·행간)·깊이·절제 절이, 움직이는 산출물엔 모션 절(스프링·중단 가능 전환)까지 적용된다. 값 충돌 시 이 파일의 토큰 정본(Pretendard·HEX)이 우선 — apple-design은 값이 아니라 공예 기준이다. 모션 출고 전 검수는 review-animations(명시 호출), 최종 확인은 실렌더.

개별 전환은 러닝타임과 다른 키로 관리한다 — 요소 등장은 아래에서 위로 {motion.transitionDuration}, 이징은 {motion.easing}. 이웃 클립은 서로 다른 워시(배경 무드)를 써서 단조로움을 피한다. stagger 값은 TODO(정본 미확정).

금지: 무한반복·글리치·Math.random(재현성 파괴). reduced-motion 상황은 전환을 최소화한다. 덱 슬라이드 전환도 같은 원칙 — 절제된 등장, 과한 모션 금지.

Do's & Don'ts

  • Do(필수·대표 강한 지시 2026-07-21) 모든 디자인 산출물에 apple-design 공예 기준을 적용한다 — 대표가 특히 지목한 세심한 포인트: ①터치·클릭 즉각 피드백(:active scale) ②중단 가능 전환(하드 리셋 금지) ③트리거에서 자라나는 transform-origin ④prefers-reduced-motion/reduced-transparency 대응 ⑤transform·opacity만 애니메이트. Don't 이 디테일을 "장식"으로 취급해 생략하지 않는다. 값(색·폰트·크기)은 이 파일 토큰이 우선, apple-design은 다듬는 법이다. 모션 있는 산출물은 출고 전 review-animations 검수.
  • Do 로고·모노그램·워드마크·리브랜딩 작업은 design-logo 스킬(한글명 디자인_로고)로 시작한다 — 5콘셉트 발산·타입 선정·이미지 프롬프트까지 스킬이 담당. Don't 스킬의 자체 채점(색 대비·16px·독창성)을 검증으로 취급하지 않는다 — 출고 전 대비는 python 실계산, 축소는 64/32/16px 실렌더 스트립, 상표 판단은 대표 영역(스킬 내 VCBio 게이트 절 참조, 조건부 도입 2026-07-23).
  • Do(대표 강한 지시 2026-07-27) 형광·네온 색은 대표 특별 요청 없이 일절 쓰지 않는다 — 무채색이 기본값이고, 강조는 명도 대비·굵기·여백으로 만든다. Don't 토큰·프리셋에 있다는 이유로 형광 채도를 쓰지 않는다(상세 = 맨 위 ⛔ 금지선 절).
  • Do(2026-07-27) 형광 판정은 감이 아니라 기계 기준으로 한다 — CIELCh L* ≥ 85 AND C* ≥ 66이면 형광이다(핵심은 채도가 아니라 밝기). Don't 채도가 높다는 이유만으로 어두운 원색을 형광으로 오판해 배제하지 않는다({colors.orange-key}·{colors.orange-gold}는 통과·존치).
  • Do(2026-07-27) 버튼은 A·B·C 3형(→ Buttons 절) 중 하나를 골라 쓰고, 주버튼엔 box-shadow: none, hover는 이동·그림자 없이 opacity:.88만 준다(한국 브랜드 22종 실측 주버튼 그림자 0곳). Don't 버튼을 새로 그리거나 알파 그림자·translate hover를 붙이지 않는다.
  • Don't(폐기 2026-07-27) 유리(글래스) 버튼을 쓰지 않는다 — 배경 11색 전부 경계 대비 3:1 미달(경계 대 버튼면 1.37~1.91:1 — 최고 1.91)로 버튼으로 안 보인다. Do 유리는 표면(네비바·카드)에만 쓴다.
  • Do 한 산출물엔 프리셋 하나만 잡는다(calm-charcoal / hot-orange / electric-blue). Don't 프리셋을 섞지 않는다(그라디언트 스톱도 프리셋 안에서만).
  • Do calm-charcoal에선 키컬러(딥그린·강조그린·골드)를 화면 5% 이하(룰선·단어·배지·작은 면)로만 쓴다. Don't calm에서 면적을 키컬러로 칠하지 않는다(보수 검토자에게 싸 보인다).
  • Do hot-*·표지·디바이더·히어로에선 키컬러 면·발광 그라디언트·풀블리드를 대담하게 쓴다(5% 룰 해제 — 단 형광 채도는 여전히 금지). Don't 단, 본문 가독 영역(데이터·표·긴 텍스트)엔 키컬러 대면적을 피한다.
  • Do 위계는 크기·웨이트 차이로만 만든다(같은 화면 3단계 이상). Don't 명시 요청 없이 Pretendard에 다른 폰트를 섞지 않는다.
  • Do 자간 트래킹은 caption ALL-CAPS에만. Don't 본문에 자간을 넓히지 않는다.
  • Do 증감은 색으로 정직하게(상승 초록·하락 빨강), 나쁜 수치도 노출한다. Don't 나쁜 수치를 숨기지 않는다.
  • Do 차트 시리즈 색은 ColorBrewer 스킴, 본문 대비·보더는 Radix sand 역할 고정. Don't 차트 색을 즉흥으로 고르지 않는다.
  • Do 풀블리드 사진은 듀오톤 + 하단 다크 그라디언트. Don't 원색 풀블리드 사진을 그대로 깔지 않는다.
  • Do 본문 대비는 WCAG 기준(≥4.5:1)을 지킨다. Don't 무한반복·글리치·랜덤 모션을 쓰지 않는다.
  • Do HTML 산출물은 항상 첫 줄에 <meta charset="UTF-8">을 포함한다(한국어 텍스트 mojibake 방지 — head 태그가 없는 조각형 HTML이어도 맨 앞에). Don't charset 선언 없이 한국어 HTML을 출고하지 않는다(생성 에이전트 연속 누락으로 한글 깨짐 실증, 2026-07-15).
